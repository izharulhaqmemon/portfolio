Industrial Equipment Failure Analysis & Prediction

Machine Learning · Predictive Maintenance

RoleAI/ML Developer
TimelineMay – Jul 2026
Outcome77.9% F1-score
Data10,000 records

Overview

A machine learning project that analyzes industrial operational and sensor data, visualizes failure patterns and predicts equipment failure.

Problem

Equipment failures cause production delays and higher maintenance costs, while scheduled inspections and post-failure repairs remain reactive.

Approach

  • Data understanding, preprocessing and exploratory data analysis
  • Feature engineering, including temperature difference and tool-wear categories
  • Removed failure-type columns to prevent target leakage
  • Trained and compared four classification models (Logistic Regression, KNN, Random Forest, Decision Tree) using accuracy, precision, recall and F1-score
  • Saved the best model for future predictions

Technical challenge

My first models scored about 99% accuracy, which was unrealistically high. The dataset contains separate failure-type columns (TWF, HDF, PWF, OSF and RNF) that directly determine the target, so the models were effectively given the answer (target leakage). I removed these columns, retrained all four models and compared them with precision, recall and F1-score, because failures are rare and accuracy alone is misleading. The realistic results are lower, and Random Forest performed best.
