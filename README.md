# Izhar Ul Haq — Portfolio

A responsive portfolio built with Next.js App Router, TypeScript, Tailwind CSS v4, Motion, and Lucide icons.

## Requirements
- Node.js 20.9 or later
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm run start
```

## Deployment notes
- Open Graph metadata is configured for https://izharulhaq-portfolio.vercel.app.
- TalashNow links to its live demo at https://talashnow.vercel.app.
- FINNAC and the predictive-maintenance project link to the GitHub profile because exact individual repository URLs were not provided; no repository URL has been guessed.
- Before publishing, make sure the displayed education details, dates, project claims, and ML metrics accurately reflect your work.

## Design & accessibility notes
- Responsive layouts at mobile, tablet, laptop, and large desktop widths.
- Semantic sections and headings, keyboard-visible focus states, and descriptive navigation labels.
- Motion respects reduced-motion preferences.
- SEO and Open Graph metadata are configured in the App Router layout.
- No external image dependencies: project visuals are custom CSS illustrations, keeping the page self-contained and fast.

Content is based on the portfolio information previously supplied. Project repository URLs and the deployed domain must be confirmed before public release.
